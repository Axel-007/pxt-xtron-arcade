Stato dell’integrazione

Questa è la prima web app contenitore. Carica la pagina originale simulator.html e i suoi file in assets/, senza copiarli, riscriverli o alterare le estensioni Xtron.

La presenza della scocca e dei controlli non significa ancora che un gioco MakeCode Arcade possa essere eseguito. Il simulatore originale definisce un proprio pxsim.Board basato su pxsim.BaseBoard e usa ScreenState/GamePlayer; serve ancora un host PXT compatibile e un adattatore per il runtime Arcade.

Non incollare qui il JavaScript compilato di Arcade: senza il runtime, il protocollo di avvio e il Board Arcade compatibile non può essere eseguito correttamente.

Prototipo di integrazione · Non modifica pxt.json né i file xtron-*.ts.
